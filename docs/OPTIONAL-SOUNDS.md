# 任意の追加効果音を設置する

公開リポジトリには運営者が追加した音源を同梱しません。利用・配信条件を確認したMP3を、次の場所へ配置してください。

```text
packages/frontend/assets/sounds/custom/通知音.mp3
packages/frontend/assets/sounds/custom/my-pack/chime.mp3
```

実際のファイル名を自動検出し、上の例では `custom/通知音` と `custom/my-pack/chime` が選択肢になります。コードへの登録や特定の名前への変更は不要です。サブフォルダーにも対応します。拡張子は小文字の `.mp3` を使用してください。

既存環境との互換性のため `packages/frontend/assets/sounds/garo/` 内のMP3も検出します。牙狼に限定した仕組みではありません。

両フォルダーはGitの管理対象外です。音源の取得・バックアップ・別サーバーへの配置は別途管理し、`git add -f` で追加しないでください。

## 反映方法

通常の依存関係の導入・初回ビルドが済んだ環境で、配置後に実行します。

```sh
pnpm --filter frontend build
```

通常の運用手順でMisskeyを再起動し、ブラウザーを再読み込みします。「設定 → サウンド」に、ビルド時に配置されていた追加音源だけが表示されます。未配置なら追加項目は表示されません。

追加・削除・名前変更の後は再ビルドが必要です。保存済み設定は自動変更しないため、使用中の音源を削除・改名した場合は選び直してください。

ビルド済み成果物やコンテナーイメージには音源が含まれます。第三者へ配布する場合は再配布条件を別途確認してください。

牙狼の公式配布元：https://www.sansei-rd.com/p_garo_archive/download/sound.html
